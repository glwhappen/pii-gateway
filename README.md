# PII 脱敏网关（pii-gateway）

在 new-api（或其他 LLM API 网关）**前面**加一层独立反向代理：
- **请求方向**：把手机号、身份证等 PII 替换为占位符，再转发给 new-api。
- **响应方向**：把模型返回里的占位符还原成真实值，再返回给客户端。

对调用方完全透明，**零改动 new-api**。这样 new-api 自己的日志、审计、计费里存的都是脱敏后的值，PII 不会进入 new-api 及上游。

```
客户端 ──▶ :3001  pii-gateway ──(脱敏后)──▶ new-api:3000 ──▶ 上游
        ◀──────────────(还原后)─────────────────◀────────
```

## 架构与数据流

```
POST /v1/chat/completions (含 138xxxx 手机号/身份证)
        │
        ▼
handleProxy: io.ReadAll(body) ─▶ 注入 system 说明 ─▶ mask() ─▶ 占位符 <<PII:TYPE:ID>> + 内存映射
        │
        ▼  透传原 Header（Authorization / Content-Type ...），只改 body
http.Client.Do() ──▶ new-api（看到的是占位符）──▶ 上游模型
        │
        ▼
响应分两种：
  · 非流式 ── io.ReadAll ─▶ restore() ─▶ 写回
  · SSE 流式 ── 逐行扫描 data: 行 ─▶ 每行 restore() ─▶ 写回并 Flush
```

映射表（占位符→真实值）在**单个请求**的调用栈内持有，用完即弃，不落盘、不共享，天然按请求隔离。

## 构建与运行

```bash
cd pii-gateway
go build -o pii-gateway .
PII_LISTEN=:3001 PII_TARGET=http://localhost:3000 ./pii-gateway
```

### 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `PII_LISTEN` | `:3001` | 网关监听地址（客户端指向这里） |
| `PII_TARGET` | `http://localhost:3000` | 转发目标（你的 new-api 地址） |
| `PII_ADMIN` | `:9090` | 管理面板端口 |
| `PII_STORE_FILE` | `pii-store.json` | 映射落盘文件（含 PII，权限 0600，不提交 git） |
| `PII_RULES_FILE` | `rules.json` | 正则规则落盘文件 |
| `PII_CONFIG_FILE` | `config.json` | 运行配置落盘文件（转发目标/端口/占位符格式/提示注入等，管理面板可改） |
| `PII_PH_PREFIX` | `<<PII:` | 占位符前缀 |
| `PII_PH_SEP` | `:` | 占位符类型与编号间的分隔符 |
| `PII_PH_SUFFIX` | `>>` | 占位符后缀 |
| `PII_SYSTEM_HINT` | （内置说明） | 注入给上游模型、提醒其保留占位符的说明文字；留空则不注入 |
| `PII_SYSTEM_HINT_ENABLED` | `off` | 是否启用提示注入（`on`/`off`，默认关闭） |

## 管理面板

网关内置一个管理 Web 面板（独立端口，不干扰转发），浏览器打开 `http://<主机>:<PII_ADMIN>` 即可：

- **状态卡片**：监听端口、转发目标、日志条数、当前时间
- **⚙️ 设置**：
  - 转发目标可在线修改（**热生效**，不用重启）
  - 代理端口/管理端口可改（保存后需重启生效）
  - **占位符格式**（前缀/分隔/后缀）可改，改后需重启并清空旧映射
  - **注入说明 + 开关**：勾选「启用注入」后，转发时会向 chat 请求注入一段 system 说明，提醒模型严格保留占位符，提升还原稳定性。说明文字与开关均**热生效**，默认关闭
- **脱敏自测**：输入一段含 PII 的文本，离线演示「脱敏 → 还原」往返（不调模型）
- **🧩 正则规则**：脱敏匹配规则列表，可增删改、可设置每条规则的**类型标签**，落盘持久
- **🗺️ 映射表**：展示全部 `占位符 <-> 真实值`，支持一键清除、手动添加
- **🌙 主题切换**：右上角按钮切换深色/浅色主题（localStorage 记忆）
- **实时转发日志**：每 1.5s 自动刷新，展示每次经过网关的请求的时间、IP、方法、路径、状态码、耗时、脱敏处数、还原处数、残留标记

日志保存在内存环形缓冲（最多 2000 条），不落盘。

## 接入 new-api

把客户端（各种 OpenAI SDK、ChatBox、NextChat 等）的 Base URL 从
`http://你的主机:3000` 改为 **`http://你的主机:3001`**，其余（API key、模型名）完全不变。

### Docker 部署示例

在 new-api 的 `docker-compose.yml` 里加一个服务即可（需能访问 new-api 容器/宿主机）：

```yaml
  pii-gateway:
    build: ./pii-gateway          # 指向本目录
    container_name: pii-gateway
    restart: always
    ports:
      - "3001:3001"
    environment:
      - PII_TARGET=http://new-api:3000   # 同 compose 网络内直接容器名
```

> 如果网关和 new-api 不在同一 Docker 网络，`PII_TARGET` 用 `http://宿主机IP:3000`。

## 占位符格式

默认格式为 **`<<PII:{类型}:{编号}>>`**，例如：

| 内容 | 占位符 |
|------|--------|
| 手机号 13812345678 | `<<PII:PHONE:1>>` |
| 身份证 110101199003071234 | `<<PII:IDCARD:2>>` |

- **类型标签**来自该真实值命中的规则（`PHONE`/`IDCARD`/`EMAIL`/`IPV4`…）；手动添加的自定义值用 `UNKNOWN`
- 前缀/分隔符/后缀可配置（`PII_PH_PREFIX`/`SEP`/`SUFFIX` 或管理面板），改后需重启并清空旧映射
- 占位符含 `<`、`>` 等可读性字符，JSON 安全，模型通常能原样回显

### 确定性映射（同一内容同一占位符）

同一真实值（同一手机号/身份证）跨请求复用**同一个占位符**，不管对话多少次都一样，方便多轮上下文连贯。映射存在全局 store（`real <-> placeholder`，带锁并发安全）。

- 同一内容 → 同一占位符；不同内容 → 不同占位符
- **持久化落盘**：映射写入 `PII_STORE_FILE`（启动时加载，重启后保持），新增即原子落盘
- **手动添加**：管理面板输入真实值（即使不匹配内置正则，如 `1111`），自动分配占位符并持久化；之后 body 中出现该值也会被替换

## 正则规则（可配置，默认 20 条）

脱敏匹配规则可在管理面板增删改、设置类型标签，落盘持久化（`PII_RULES_FILE`）。默认规则（按执行顺序）：

| 规则名 | 类型标签 | 示例 |
|--------|---------|------|
| 银行卡号 | `BANKCARD` | 6222021234567890123 |
| 中国大陆身份证 | `IDCARD` | 110101199003071234 |
| 中国大陆手机号 | `PHONE` | 13812345678 |
| 邮箱 | `EMAIL` | abc@test.com |
| 中国大陆车牌 | `PLATE` | 粤B12345 |
| 固定电话 | `LANDLINE` | 0755-12345678 |
| 中国护照 | `PASSPORT` | E12345678 |
| 港澳通行证 | `HKMO_PASS` | H12345678 |
| 统一社会信用代码 | `CREDIT_CODE` | 91310115MA1K3N5D6X |
| 组织机构代码 | `ORG_CODE` | 12345678-9 |
| IPv4 地址 | `IPV4` | 192.168.1.100 |
| IPv6 地址 | `IPV6` | 2001:0db8:… |
| MAC 地址 | `MAC` | aa:bb:cc:dd:ee:ff |
| JWT | `JWT` | eyJhbGciOi… |
| Bearer Token | `BEARER` | Bearer eyJ0eXAiOi… |
| 模型/OpenAI API Key | `API_KEY` | sk-abcdef… |
| GitHub Token | `GITHUB_TOKEN` | ghp_ABCD… |
| AWS Access Key | `AWS_KEY` | AKIAIOSFODNN7EXAMPLE |
| PEM 私钥 | `PEM_KEY` | -----BEGIN RSA PRIVATE KEY-----… |
| 美国社会安全号 | `SSN_US` | 123-45-6789 |

规则**按执行顺序**执行。API：`GET /api/rules` 列表、`POST /api/rules` 添加、`POST /api/rules/update` 更新、`POST /api/rules/remove` 删除。非法正则会拒绝。

> ⚠️ **规则重叠注意**：正则按顺序逐个执行，先执行的正则会吃掉重叠部分。银行卡已带 BIN 前缀并放在最前，避免 19 位卡被身份证规则截断。新增自定义规则时，若与现有规则数字长度重叠（如银行卡 vs 身份证），请注意顺序或设计互斥正则。

### 占位符保留提示（可选，默认关闭）

LLM 可能改写或拆分占位符导致还原失败。网关可配置在转发前向 chat 请求的 `messages` 最前插入一条 system 说明，提醒模型严格原样保留 `<<PII:...>>` 占位符，显著提升还原稳定性：

> 请严格原样保留所有形如 `<<PII:...>>` 的占位符：不得翻译、改写、增删字符、改变大小写、添加/删除空格、拆分或合并。输出中必须与输入完全一致。

- 开关默认关闭（`PII_SYSTEM_HINT_ENABLED=off`）；开启后热生效
- 说明文字可改（管理面板或 `PII_SYSTEM_HINT`）；仅对含 `messages` 数组的 OpenAI 风格请求注入，其他请求原样转发

## 局限与后续可做

- **占位符被模型改写**：若模型不回显占位符、或改写成别的格式，还原会失败，客户端会看到 `<<PII:...>>`。开启「占位符保留提示」可显著缓解；极端情况可考虑重试或告警。
- **跨 chunk 拆分已处理**：模型按 token 流式输出时，占位符可能被拆到相邻多个 `data:` 行的 content 字段里（甚至逐字拆）。网关按 content 值做跨行拼接（`carry` 状态机），支持任意拆分位置，还原后才写回客户端。
- **只覆盖文本类接口**：当前对任意请求体做文本替换，对 embedding/image 等二进制也可能误匹配，建议只把 `/v1/chat/completions`、`/v1/responses` 等文本路由指向网关。
- **映射落盘存储 PII**：`PII_STORE_FILE` 存有「真实值 <-> 占位符」明文对应关系，属 PII 存储点。文件权限 0600，仅 root 可读；管理面板映射表也会明文展示真实值。**建议给管理面板加访问控制**（NPM Access List / Basic Auth），避免 PII 暴露。
- **短手动值的误匹配**：手动添加的值（如 `1111`）会按子串替换，`21111` 等包含它的内容也会被替换，需注意选择足够独特的真实值。
- **假值替换 vs 占位符**：当前用占位符（最安全）。如需模型上下文更自然，可改为「替换成合法假值」+ 映射还原，但模型改写假号时还原不可靠。
